# Interview PlayBook

- **Think / Write approaches:**
- **Think / Write all the Edge cases. Discuss and confirm edge cases even when you know them or have assumed them as they are obvious** 
- **Think / Write time and space Complexity (tell it to the interviewer only when asked)**
- **Confirm approach with the interviewer**
- **Write pseudocode / steps for the code**
- **Write the complete code**
